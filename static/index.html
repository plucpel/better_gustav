    Extension Chrome GUSTAV pour Medesync DME

    Cette extension officielle permet d'injecter un bouton direct « 🧪 GUSTAV » dans les dossiers patients de Medesync. Elle synchronise instantanément les renseignements du patient (RAMQ, Nom, Date de naissance, Prescripteur) avec bypass automatique du PIN et sans laisser aucune trace dans l'historique ou les logs.

    1. Télécharger l'Extension

    Téléchargez l'archive prête à l'emploi contenant le Manifest V3 et les scripts.

    Télécharger l'Extension (.ZIP)
    2. Paramètres de Connexion pour vos Postes
    URL du Serveur GUSTAV
    http://chatterbox:8000
    Clé Secrète Clinique (Secret Key)
    gustav_ext_secret_chatterbox_2026
    3. Guide d'Installation Rapide (1 minute)
    1. Décompressez le fichier gustav-medesync-extension.zip sur votre poste.
    2. Dans Google Chrome, naviguez vers chrome://extensions/.
    3. Activez le « Mode développeur » (en haut à droite).
    4. Cliquez sur « Charger l'extension non empaquetée » et sélectionnez le dossier décompressé.
    5. Cliquez sur l'icône de l'extension dans Chrome pour vérifier ou coller l'URL du serveur et la clé secrète.
